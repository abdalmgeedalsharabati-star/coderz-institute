1. فحص لون عنوان الكورس (Specificity)
- التوقع: سيظهر عنوان h1 باللون البنفسجي (purple).
- النتيجة في DevTools -> Styles: القاعدة التي تحدد اللون هي #course-title { color: purple; }، واللون الظاهر هو purple.
- السبب: لأن محدد المعرّف (#course-title) له Specificity أعلى (1,0,0) من محدد الفئة (.title) (0,1,0) ومحدد العنصر (h1) (0,0,1). لا تفوز قاعدة h1 رغم أنها مكتوبة بعد القاعدتين الأخريين لأن Source Order لا يُحسم إلا عند تساوي الـ Specificity.

2. تغيير ترتيب قاعدتين (Source Order)
- الحالة الأولى (بعد تعطيل #course-title مؤقتاً وإضافة .title { color: orange; } في نهاية الملف):
  - التوقع: سيظهر العنوان باللون البرتقالي (orange).
  - النتيجة: ظهر العنوان باللون البرتقالي (orange).
  - السبب: بعد تعطيل #course-title أصبحت القاعدتان الأعلى هما .title { color: green; } و .title { color: orange; } بنفس الـ Specificity (0,1,0)، ففازت القاعدة المكتوبة أخيراً (orange) حسب Source Order.
- الحالة الثانية (بعد نقل .title { color: orange; } إلى ما قبل .title { color: green; } مباشرة):
  - التوقع: سيعود العنوان إلى اللون الأخضر (green).
  - النتيجة: ظهر العنوان باللون الأخضر (green).
  - السبب: لتساوي القاعدتين في الـ Specificity (0,1,0)، أصبحت .title { color: green; } هي الأخيرة في ترتيب الملف ففازت.

3. تتبع لون الفقرتين (Inheritance)
- التوقع قبل التعديل: سترث كلتا الفقرتين لون البطاقة (#374151).
- النتيجة قبل التعديل في DevTools -> Computed: كلتا الفقرتين لهما اللون rgb(55, 65, 81) (#374151) موروثاً من .course-card.
- بعد إضافة القاعدة .course-card > p { color: teal; }:
  - التوقع: تصبح الفقرة التعريفية بلون teal، بينما تبقى فقرة الموعد وارثةً للون البطاقة (#374151).
  - النتيجة في DevTools -> Computed: الفقرة التعريفية لونها rgb(0, 128, 128) (teal)، وفقرة الموعد (Next class: Monday) لونها rgb(55, 65, 81) (#374151).
  - تفسير الاختيار بين > و (المسافة): استخدمتُ Child Combinator (>) في .course-card > p لأنه يطابق فقط عنصر <p> الابن المباشر لـ .course-card (الفقرة التعريفية)، ولا يطابق <p> الموجود داخل <div class="details"> (فقرة الموعد)، مما يسمح لفقرة الموعد بأن تستمر في وراثة لون .course-card. أما Descendant Combinator (المسافة) .course-card p فكان سيطابق كلتا الفقرتين ويجعلهما teal معاً.

4. اختبار الرابط (:hover و :focus-visible)
- التوقع: يتغير لون الرابط عند تمرير الفأرة فوقه، ويظهر outline مرئي عند الوصول إليه بمفتاح Tab.
- النتيجة والسبب:
  - عند مرور المؤشر على الرابط: تغيّر لونه إلى crimson بسبب قاعدة a:hover، وعند إبعاد المؤشر عاد للونه الطبيعي.
  - عند إبعاد المؤشر والضغط على Tab للوصول إلى الرابط: ظهر إطار outline واضح حوله (2px solid #0f4c5c) بسبب تفعيل قاعدة a:focus-visible عند التركيز عبر لوحة المفاتيح.
